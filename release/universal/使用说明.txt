工资表工具 通用版
版本：1.2.0

一、适用电脑

本工具可在 Windows、macOS 和常见桌面 Linux 电脑使用，不需要安装专用软件。
建议使用最新版 Microsoft Edge、Google Chrome 或 Safari。

手机微信和微信内置预览不能完成工资表生成。请先在电脑微信中下载压缩包。

二、打开方式

1. 双击收到的 ZIP 压缩包，解压全部内容。
2. 把解压出的整个“工资表工具-通用版-v1.2.0”文件夹放到电脑上的常用位置。
3. 双击文件夹里的“打开工资表工具.html”。
4. 如果电脑没有自动用浏览器打开，请右键该文件，选择使用 Edge、Chrome 或 Safari 打开。

请保留整个文件夹，不要只移动“打开工资表工具.html”，也不要在压缩包预览窗口中直接运行。

三、生成下月工资表

1. 选择上月已经确认的完整工资表。程序会从工资表标题识别月份，并自动生成下一个自然月。
2. 一次选择目标月份收到的全部工资附件，程序会读取所选的全部有效文件。
3. 如有人员、工资、考勤、绩效或提成等变化，用文字、变动表或程序可识别的业务
   Excel/Word 输入本月变化。
4. 在页面逐项确认附件“已读取”、月份提醒、人员和字段匹配结果。这是生成前的第一道
   人工核对。
5. 预览无错误后生成“待复核”工资表。
6. 用桌面版 Excel 打开生成文件，完整重算并由财务逐项复核。这是第二道人工审核，
   审核通过后才能作为正式工资表。

目标为一月时，程序会另外要求选择上一年度 12 个月工资表。

四、附件范围

程序目前按已验证格式读取：

- 个税附件；
- 社保、公积金附件；
- 工作簿结构要求时的劳务费附件；
- 员工动态、入职转正薪资、实习生津贴、考勤等人员和工资变动表；
- 人员和工资变动文字或其他表格；
- 已验证格式的实习生津贴、保密津贴和保密补贴审批表。

附件并不是任意格式都能自动处理。无法识别、人员无法唯一匹配、字段缺失或辅助工作表无法安全同步时，程序会停止生成并提示错误。

是否沿用按字段来源判断，不按数值是否变化判断。目标月份个税、社保、公积金和劳务费
附件即使数值与上月相同，也会重新写入。季度绩效、提成、其他工资和扣款等一次性项目
先清空再等待本月资料；BM 津贴按季度资料复核。

实习生津贴或保密补贴资料会先形成逐人预览。新实习生若不在上月工资表，必须先提供
完整人员变动信息；只有人员名单、没有金额的资料不能用于推算工资或补贴。

含身份证号的人员变动表只按身份证匹配，不会在身份证未命中时改用姓名。劳务费与当前
草案金额不同可能是临时劳务费、本月新增或本月金额变化，页面会显示中性复核提醒，
但不会因此阻断写入；财务仍需在生成前后确认当月劳务费金额。

考勤表中的工作部门可以为空。程序按具体假别和天数计算已确认的病假、事假扣款；
转正人员缺少转正天数，或产假、工伤等缺少完整规则时会停止并提示补充资料。

如果工资表或附件有打开密码，程序会弹出“请输入密码”。密码错误可以重新输入，
不同文件可以使用不同密码；取消后该文件不会导入。密码只用于本次本地读取，不会保存
到程序、浏览器存储或生成文件。

同时选择多个附件且只有一个文件有密码时，输入正确密码后会继续核对整批文件。页面会
分别显示“已读取”和“通过核对”的数量。如果文件已读取但提示人员缺失，请先到
“人员 / 工资变动”录入本月的停用、新增或身份信息更正，再重新选择附件。

如果目标月份附件的文件名正确，但内部工作表名仍是紧邻的上一个月，程序会在唯一匹配时
继续读取并显示月份提醒。请人工确认该附件确实是目标月份数据；更早月份或多个同等匹配
工作表仍会停止。

五、数据安全

- 所有读取、核对和生成都在当前电脑的浏览器中完成，不上传网络。
- 程序包不包含任何真实工资表、姓名、身份证号、银行卡号或工资数值。
- 生成文件默认为“待复核”，请勿跳过财务复核。
- 本工具把资料整理成可供二次审核的草案，不自动代替财务审批。
