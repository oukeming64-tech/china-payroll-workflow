工资表工具 通用版
版本：1.0.0

一、适用电脑

本工具可在 Windows、macOS 和常见桌面 Linux 电脑使用，不需要安装专用软件。
建议使用最新版 Microsoft Edge、Google Chrome 或 Safari。

手机微信和微信内置预览不能完成工资表生成。请先在电脑微信中下载压缩包。

二、打开方式

1. 双击收到的 ZIP 压缩包，解压全部内容。
2. 把解压出的整个“工资表工具-通用版-v1.0.0”文件夹放到电脑上的常用位置。
3. 双击文件夹里的“打开工资表工具.html”。
4. 如果电脑没有自动用浏览器打开，请右键该文件，选择使用 Edge、Chrome 或 Safari 打开。

请保留整个文件夹，不要只移动“打开工资表工具.html”，也不要在压缩包预览窗口中直接运行。

三、生成下月工资表

1. 选择上月已经确认的完整工资表。程序会从工资表标题识别月份，并自动生成下一个自然月。
2. 如有人员、工资、考勤、绩效或提成等变化，用文字或变动表输入本月变化。
3. 选择目标月份的工资附件，并逐项确认人员和字段匹配结果。
4. 预览无错误后生成工资表。
5. 用桌面版 Excel 打开生成文件，完整重算并逐项复核后，才能作为正式工资表。

目标为一月时，程序会另外要求选择上一年度 12 个月工资表。

四、附件范围

程序目前按已验证格式读取：

- 个税附件；
- 社保、公积金附件；
- 工作簿结构要求时的劳务费附件；
- 人员和工资变动文字或表格。

附件并不是任意格式都能自动处理。无法识别、人员无法唯一匹配、字段缺失或辅助工作表无法安全同步时，程序会停止生成并提示错误。

原始加密的社保文件需要先在 Excel 中打开，再另存为无密码的 .xlsx 文件。

五、数据安全

- 所有读取、核对和生成都在当前电脑的浏览器中完成，不上传网络。
- 程序包不包含任何真实工资表、姓名、身份证号、银行卡号或工资数值。
- 生成文件默认为“待复核”，请勿跳过财务复核。

六、误删后的恢复

如果本工具或维护包被误删，请打开：

https://github.com/oukeming64-tech/china-payroll-workflow

进入 Releases，重新下载最新的“工资表工具-通用版”即可。需要让 Codex 修改程序时，
下载同一版本的“工资表工具-维护版”。
