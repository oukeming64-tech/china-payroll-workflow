# 验收清单

## 功能

- [x] 普通月份由上月已确认工资表生成下月待复核工资表；
- [x] 一月要求并实际消费上一年度 12 个月；
- [x] 个税、社保、公积金及其他必需来源逐项显示匹配预览；
- [x] 来源月份、字段或人员不匹配时停止；
- [x] 人员和工资变动同步全部经验证的相关工作表；
- [x] 导出文件保留应有工作表、内部公式和样式；
- [x] 导出文件外链关系、外链部件和外部公式均为 0；
- [x] 结果始终提示由财务在 Excel 中重算复核。

## 测试

- [x] 架构方向和文件大小门禁通过；
- [x] 无个人信息合成端到端测试 8 项全部通过；
- [x] 普通月、一月、缺失附件、人员冲突和事务回滚均有覆盖；
- [x] 通用版是无平台运行时依赖的静态 ZIP，并通过当前 Mac Chromium 验证；
- [x] 发布包不含 Excel、CSV、Word、PDF、真实回放或 Git 历史；
- [x] 维护版在全新解压目录中可安装、测试并重新生成两种 ZIP；
- [ ] 在实际 Windows Edge 和另一台 Mac Safari 完成人工全流程检查。

## 隐私与发布

- [x] 当前树扫描不到个人信息、密钥和本机路径；
- [x] 公司名、内部工作簿名、真实工作簿哈希和内部统计未进入公开版；
- [x] SheetJS 与 JSZip 第三方许可完整保留；
- [x] 项目代码采用 Apache License 2.0，第三方许可单独保留；
- [x] 公开仓库从脱敏白名单导出建立全新历史，而非推送内部仓库历史。
