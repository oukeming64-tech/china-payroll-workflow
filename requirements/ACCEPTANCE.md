# 验收清单

## 功能

- [x] 普通月份由上月已确认工资表生成下月待复核工资表；
- [x] 一月要求并实际消费上一年度 12 个月；
- [x] 个税、社保、公积金及其他必需来源逐项显示匹配预览；
- [x] 来源月份、字段或人员不匹配时停止；
- [x] 加密工作簿弹出密码框；错误可重试、取消不导入、不同文件可使用不同密码；
- [x] 三类附件仅一份加密时，正确密码后保留整批 3/3 类读取结果；
- [x] 文件名为目标月、唯一工作表名仍为紧邻上月时读取并显示月份提醒；
- [x] 页面分开显示“已读取”和“通过核对”，人员差异提示先录入人员变动；
- [x] 相同值的目标月附件字段仍形成实际写入，不按“是否变化”决定是否读取；
- [x] 草案重置一次性绩效、提成、其他工资、考勤/其他扣款、年度绩效和代扣借款；
- [x] 1、4、7、10 月绩效与 3、6、9、12 月保密补贴资料门禁正确；
- [x] 实习生津贴、保密津贴和保密补贴 Word 按已证明字段形成逐人预览；
- [x] 只有人员名单、没有金额的资料明确停止；
- [x] 一次选择的全部目标月附件都被读取，同一工作表的多个变动区段分别处理；
- [x] 有身份证的人员变动严格按身份证匹配，缺失或未命中时停止；
- [x] 上月完整工资表的离职名单、备忘等分表按业务日期形成待确认项，确认后的既往
  离职不再误报为目标月附件缺人；
- [x] 转正统一按生效月份 1 日采用整月工资，不再要求转正天数或试用天数；
- [x] 普通劳务费金额差异只显示复核提醒、不阻断写入，高税档仍停止；
- [x] 病假、事假扣款公式有覆盖，工作部门可空且请假信息分组头不要求目标表同名字段；
- [x] 已有人员工资或考勤变动保留`实发合计`公式，并让`代发薪`内部引用该结果；
- [x] 没有实发公式且来源未明确金额时停止；辅助表缺行仅在同批确认离职可提供安全
  复用行、公式、身份和银行账号均可证明时继续；
- [x] 人员和工资变动同步全部经验证的相关工作表；
- [x] 导出文件保留应有工作表、内部公式和样式；
- [x] 导出文件外链关系、外链部件和外部公式均为 0；
- [x] 结果始终提示由财务在 Excel 中重算复核。
